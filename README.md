# RoyalWares Public Releases Hub

Bu repozitoriya **RoyalWares** Android tətbiqlərinin rəsmi imzalanmış buraxılış APK fayllarını və tətbiqdaxili yeniləmə yoxlaması üçün istifadə olunan `manifest.json` indeksini saxlayır.

- Mənbə kodları şəxsi (Private) repozitoriyalarda saxlanılır.
- Tətbiqlər (`RoyalDiet Balance`, `RoyalNotes PRO`, `RoyalTube PRO`, `RoyalWares Xatırladıcı Pro`, `RoyalFile Manager PRO`) yeniləmələri `manifest.json` üzərindən SHA-256 doğrulaması ilə yoxlayır və endirir.
